# Interview Prep

Read `_SKILL.md` for private candidate context (metrics, compensation, pipeline status).

## Workflow

Given a job description or company name, execute these 5 steps:

1. **Role Mapping** — Extract tech requirements from the JD and map directly to Daniel's core stack: AWS (EMR, Fargate, CDK, S3, DynamoDB, RDS, EventBridge), Spark, Docker, Temporal, PostgreSQL, FastAPI, RAG/LLMs, DSPy, MLflow.

2. **System Design & Topics** — Identify 2-3 high-probability system design patterns or architectural topics likely to come up. Be specific to the role.

3. **STAR Stories & Metrics** — Select 2-3 tailored STAR stories from `../../applications/personal_context.md` with verifiable numbers. Never fabricate metrics.

4. **Gap Pivots & Anchors** — For missing tools (e.g., Azure), provide exact pivot scripts. Example: "0 years Azure, extensive AWS — cloud compute principles transfer rapidly." Reiterate the target contractor anchor.

5. **PR Review / Seniority Check** — If asked how to handle a teammate's PR, position as a Senior: advise asking clarifying questions first — who is sending this, what is the project context, timeline, platform boundaries, how many teammates are involved. Frame the review as a collaborative systems-level check, not a syntax check.
