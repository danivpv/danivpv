# Job Description Triage

Read `_SKILL.md` for private candidate context (location, visa status, compensation floor).

## Triage Rules

1. **Anti-Targets** — Skip immediately: pure frontend, non-coding research, roles requiring active US Security Clearance. Do NOT skip AI/ML roles just because of corporate HR tech stack mismatches.

2. **Relocation / Visa** — Check `_SKILL.md` for current location, acceptable relocation targets, and visa sponsorship requirements. Explicitly flag any visa requirements in application drafts.

3. **Stack Flexibility** — Python/AWS experience is highly transferable. Pivot confidently to Azure/.NET adjacent stacks when the core role is AI/ML engineering.

4. **Survival Tier** — Check `_SKILL.md` for current financial constraint status. When active, part-time, contract, and easy-fill roles are IN SCOPE alongside the senior search.
   - **Approve**: AI trainer, education/curricula, AI product QA/evaluation, technical support.
   - **Apply immediately** — short cycles, faster hiring, do not over-tailor.
   - **Rule**: Never anchor senior salary expectations on part-time income.

5. **Blog Signal** — Flag roles where active or planned blog series (see `_SKILL.md`) would materially strengthen the application — recommend deferring those until the post is live.

## Output Format

Three tiers, in this order:

**(a) Senior roles — apply now**
- Brief fit assessment + immediate draft or next step

**(b) Senior roles — defer**
- Reason for deferral (usually: AI blog not yet live)

**(c) Survival/part-time — apply immediately**
- Simple cover note, no over-tailoring
